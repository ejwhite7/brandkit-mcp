# Brand Atomic System

This directory contains your brand design system in the v2 brand_atomic_system layout.

- `magic_trick.md` — Start here. One paragraph that captures the brand's essence.
- `agent/verbal/` — Your positioning, audience, messaging, voice, and creative concepts.
- `agent/visual/` — Your CSS tokens, component specs, token specimens, motion, fonts, and assets.

Fill in each file with your brand's content. See `examples/acme-corp/` for a complete example.
