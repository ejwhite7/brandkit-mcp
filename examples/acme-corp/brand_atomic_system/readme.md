# Acme Corp Brand Atomic System

This directory contains the complete Acme Corp design system in the v2 brand_atomic_system layout.

## Structure

- `magic_trick.md` — The one-paragraph essence of the brand; read this first.
- `agent/verbal/` — Verbal identity: positioning, audience, messaging, voice, differentiation, creative concepts.
- `agent/visual/` — Visual identity: CSS tokens, component specs, token specimens, motion, fonts, and assets.
- `agent/visual/artifacts/web/` — Web (marketing site) overrides layered on top of the base visual layer.
- `agent/visual/artifacts/product/` — Product (app UI) overrides layered on top of the base visual layer.

## Contexts

- **base** — Shared visual defaults used by both web and product.
- **web** — Public marketing site (acme.com). Slightly warmer accent palette.
- **product** — SaaS application (app.acme.com). Tighter radius for dense UI.
