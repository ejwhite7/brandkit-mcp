# Radius: Default

`8px`

The standard rounding for most UI surfaces. Creates a friendly but not overly rounded aesthetic appropriate for a developer-focused product.

| Token | Value | Use |
|---|---|---|
| `--radius-sm` | 4px | Badges, tags, small chips |
| `--radius-default` | 8px | Cards, buttons, inputs |
| `--radius-lg` | 12px | Modals, drawers, large panels |
| `--radius-full` | 9999px | Pills, avatar rings, toggle tracks |
