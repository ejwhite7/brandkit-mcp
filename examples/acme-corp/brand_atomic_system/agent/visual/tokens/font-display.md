# Font: Display

`Inter` (with system-ui fallback)

Inter is used for all display text: page titles, section headings, feature names, and large-format numbers. Its geometric proportions and generous x-height make it readable at both large (60px+) and small (14px) sizes.

**Weight guidance:** Headings should use `600` (semibold) or `700` (bold). Avoid weights below `500` in display contexts.
