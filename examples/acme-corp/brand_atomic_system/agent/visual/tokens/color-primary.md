# Color: Primary

`#1a56db` — Acme Blue

The primary action color. Use for the main CTA on any given page or view. Limit usage to one or two elements per screen to preserve emphasis.

Passes WCAG AA contrast (4.8:1) on white backgrounds. Use white text on primary-filled backgrounds.
