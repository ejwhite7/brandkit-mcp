# Font: Body

`Inter` (with system-ui fallback)

The same typeface as display, used at smaller scales for body text. At 16px with `--line-height-normal` (1.5), Inter is highly legible for prose. At 14px (UI labels) use `--font-weight-medium` (500) to compensate for reduced contrast.

**Minimum size:** 12px for supporting text. Never use Inter below 11px in production UI.
